# Cmd Bridge

Маленькая утилита для безопасного выполнения команд, которые предлагает
ассистент в чате. Работает как «мост»: вы копируете команду из чата,
утилита сама подхватывает её из буфера обмена, показывает, предупреждает
об опасных операциях и выполняет **только после вашего подтверждения**.

Ничего не устанавливает: чистый Python (стандартная библиотека), без зависимостей.

## Быстрый старт (Windows)

1. Дважды кликните `CmdBridge.cmd` — откроется командное окно.
2. В чате с ассистентом скопируйте предложенную команду
   (кнопка «копировать» у блока кода или просто выделите и `Ctrl+C`).
3. Cmd Bridge подхватит текст из буфера, покажет его и предложит меню:

   ```text
   1 — выполнить   2 — пропустить   3 — редактировать   4 — выход
   ```

   Меню работает одним нажатием клавиши — **без Enter**, и цифры
   одинаковы в любой раскладке клавиатуры.

4. После `1` команда выполняется прямо в этом окне — вывод виден сразу.
5. Вывод **автоматически копируется в буфер обмена**, подписанный
   конвертом `FMR-BRIDGE-OUT` (включая код выхода и контрольную сумму).
   Осталось вставить его в чат ассистенту — ничего нажимать не нужно.

## Что делает утилита автоматически

- **Снимает markdown-обёртки.** Если вместе с командой скопировались
  ```` ``` ````-заборы (```powershell, ```cmd и т.п.) — они удаляются;
  язык блока используется, чтобы выбрать между `cmd.exe` и PowerShell.
- **Определяет диалект.** Однострочные команды выполняются через `cmd.exe`,
  PowerShell-скрипты — через `powershell.exe -ExecutionPolicy Bypass -File`.
- **Кодировки.** Кириллица в командах и выводе не ломается
  (временные скрипты исполняются в UTF-8).
- **Предупреждает об опасном.** `rd /s`, `format`, `diskpart`, `reg delete`,
  `shutdown`, `Remove-Item -Recurse` и т.п. помечаются красным флагом,
  и для запуска нужно нажать `1` два раза подряд (второе нажатие —
  отдельное подтверждение).
- **Пишет историю.** Каждая выполненная команда и её код выхода
  дописываются в `cmd_bridge_history.log` рядом с утилитой (вывод не пишется).

## Ничего не запускается без вас

Утилита только следит за буфером обмена. Само копирование и нажатие `1` —
всегда ваше действие. Закрыть окно или нажать `4` можно в любой момент.

## Параметры командной строки

```bat
CmdBridge.cmd --once            :: выполнить одну команду и выйти
CmdBridge.cmd --dir D:\work     :: выполнять команды в указанной папке
CmdBridge.cmd --text "dir C:\"  :: выполнить конкретную команду (без буфера)
```

## Подпись команд (защита от случайного буфера)

Мост выполняет только команды с подписью ассистента. Каждая команда из
чата приходит в конверте:

```text
-----FMR-BRIDGE v1 sha1:<контрольная сумма>-----
сама команда
-----END FMR-BRIDGE-----
```

Контрольная сумма — SHA-1 от текста команды после нормализации
(концы строк и хвостовые пробелы не учитываются). Поэтому:

- случайный кусок текста в буфере **не выполняется** — мост пишет
  «Пропущено: текст без подписи FMR-BRIDGE» и ждёт дальше;
- текст, изменившийся при копировании, отклоняется с сообщением
  о несовпадении суммы;
- вывод каждой команды заворачивается в ответный конверт
  `-----FMR-BRIDGE-OUT v1 exit:<код> sha1:<сумма>-----`, так что
  ассистент отличает вывод моста от случайного текста и видит, если
  он обрезался.

Скопированный обратно вывод моста (конверт `FMR-BRIDGE-OUT`) мост
командой не считает и игнорирует.

Если нужно выполнить что-то без подписи (например, старую команду
из переписки): запустите с флагом `--allow-unsigned`.

## Инструкция для другой модели/агента

Чтобы с мостом начала работать другая модель или агент, нажмите `5`
в любой момент (в меню команды или просто в окне ожидания) — в буфер
обмена скопируется готовая инструкция в конверте `FMR-BRIDGE-INFO`:
что такое мост, в каком формате присылать команды (конверт
`FMR-BRIDGE` с контрольной суммой), что приходит обратно
(`FMR-BRIDGE-OUT` с кодом выхода) и какие действуют правила
безопасности. Вставьте её в чат другой модели — и она сможет слать
подписанные команды без дополнительных объяснений.

## Обновление

Двойной клик по:

```text
UpdateCmdBridge.cmd
```

Скрипт скачивает свежие версии файлов папки `tools/cmd-bridge` из ветки
`main` на GitHub и заменяет локальные копии. Перед заменой старые файлы
сохраняются в подпапку `backup_<дата_время>` (её можно удалить вручную).
Обновляется только эта папка — остальной репозиторий не трогается.

Так как репозиторий приватный, для скачивания нужен один из вариантов:

1. переменная окружения `GITHUB_TOKEN` — персональный токен
   (GitHub → Settings → Developer settings → Personal access tokens,
   достаточно права **Contents: Read**);
2. переменная окружения `GH_TOKEN`;
3. установленный GitHub CLI, в котором выполнен `gh auth login`.

Если ничего из этого нет, обновление завершится с подсказкой и ни один
файл не будет изменён.

## Если сбился шрифт или кодировка в окне

Команды временно включают кодовую страницу 65001 (UTF-8), и старая
консоль из-за этого может поменять шрифт. Утилита сама возвращает
кодовую страницу и шрифт после каждой команды; если окно уже «съехало»:

1. наберите в этом окне `chcp 866` и Enter — вернётся кириллическая
   кодовая страница;
2. правый клик по заголовку окна → **Свойства** → вкладка **Шрифт** →
   выберите **Consolas** или **Cascadia Mono** → ОК;
3. либо просто закройте окно и запустите `CmdBridge.cmd` заново.

Лучше всего мост выглядит в **Терминале Windows** (Windows Terminal) —
там шрифт по умолчанию не сбивается вовсе.

## Если буфер не подхватывается

- Убедитесь, что скопирован именно текст команды (например, кнопкой
  копирования у блока кода в чате).
- Если окно запущено от имени администратора, а источник копирования — нет
  (или наоборот), буфер может не читаться; запустите `CmdBridge.cmd`
  с тем же уровнем прав.

## Не Windows

На других системах утилита работает в режиме ручного ввода: вставляете
команду в консоль, завершаете пустой строкой — дальше то же подтверждение.
